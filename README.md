# Attraction Recode Website

Open `index.html` in a browser.

## Structure
- `index.html` — page content
- `css/styles.css` — all layout and styling
- `js/main.js` — smooth scrolling
- `images/hero-extended.jpg` — extended desktop hero image
- `images/tamara-original.jpg` — untouched source image
- `images/tamara-profile.jpg` — circular profile crop
- `images/icon-*.svg` — editable line icons

## Easy edits
- Replace the booking URL `https://calendly.com/` in `index.html`.
- Replace `images/hero-extended.jpg` with another image using the same filename.
- SVG icons can be edited in any text editor; change `#ff5d66` to another accent color.
- Mobile image positioning is in `css/styles.css` under `@media(max-width:900px)`.
